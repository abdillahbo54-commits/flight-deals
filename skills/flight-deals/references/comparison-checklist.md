# Comparison checklist

Use this list before recommending an offer.

## Price
- [ ] Total for **all** passengers, with currency
- [ ] Checked bag fee added if not included
- [ ] Seat selection / payment / service fees noted
- [ ] Same fare checked on at least two sources when possible

## Itinerary
- [ ] Stops and layover duration (under 1h30 international = tight; over 8h = long)
- [ ] Overnight layover or airport change (and whether a visa/transit permit is needed)
- [ ] Arrival time reasonable (late-night arrivals: transport options?)
- [ ] Total duration vs the fastest option

## Fare conditions
- [ ] Refundable / changeable / non-refundable
- [ ] Cabin bag size and weight limits (low-cost carriers)
- [ ] Self-transfer (separate tickets) flagged as a risk

## Flexibility tips
- [ ] ±3 days around the requested dates
- [ ] Mid-week departures vs weekends
- [ ] Nearby airports (same country or neighboring city)
- [ ] One-way x2 vs round trip
- [ ] Booking window: very close departures are usually pricier

## Output
- [ ] Same-price offers that differ only by times grouped into one row
- [ ] Compact top-5 table first, detail offered afterwards
- [ ] Cheapest / fastest / best-balance picks
- [ ] Tool display rules kept (exact price, `table_headers`, unmodified deeplink, neutral tone)
- [ ] Failed sources listed in one line each
- [ ] Tracking-parameter notice under the links
- [ ] Search date and time stated
- [ ] Booking links included, no booking made
