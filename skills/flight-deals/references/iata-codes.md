# IATA codes — common cities and airports

**Rule: prefer the city code** when a city has several airports (PAR, LON,
NYC…). It covers every airport at once and finds more offers. Use an airport
code only when the user names a specific airport or the city has a single
airport (then city and airport codes are often the same). If a city is not
listed, use the tool's own place lookup or the airport's official site.

If a tool rejects a city code, retry once with the main airport code.
